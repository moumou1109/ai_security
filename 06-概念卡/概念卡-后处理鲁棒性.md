# 概念卡 · 后处理鲁棒性（Post-processing Robustness）

## 1. 定义

- 通俗版：内容在网上传播时会经过平台压缩、缩放、转码、截图、混剪……检测器在这些「二手内容」上还准不准。
- 学术版：检测器在输入经过一系列**非恶意但会改变分布的变换**（JPEG/H.264 压缩、尺寸缩放、高斯模糊、色彩/亮度调整、旋转、噪声、超分）后，维持判别性能的能力。

## 2. 为什么重要

真实传播链与实验室条件之间隔着一整套后处理：

```
生成器产出（原生、干净）
   ↓ 上传
平台压缩（JPEG / H.264，质量/码率未知）
   ↓ 分发
二次编辑（裁剪、缩放、混剪、加字幕、截图）
   ↓ 再次上传
再次压缩 …
```

这条链会**系统性破坏伪造线索**：

- 压缩 = **低通滤波** → 抹掉高频伪影（直接打击 [[概念卡-频域伪影]] 类方法）；
- 缩放/重采样 → 破坏混脸边界与重采样一致性；
- 多次转码 → 叠加、非线性的复合退化。

这正是 RQ-001 的「后处理分支」要在**受控条件**下量化的事情。

## 3. 常见误解

- **误解 1**：以为后处理影响很小。真实证据是：平均准确率可从干净条件 94.7% 掉到退化条件 67.8%（Δ ≈ −26.9%），JPEG 与运动模糊最多造成 35% 下降（见 [[证据卡-Robustness2026-01]]）。
- **误解 2（关键方法学陷阱）**：在**已经退化过的样本**上追加后处理，会发现影响「很小」（性能变化比 0.9–1.1）——这是**饱和效应**，不是鲁棒性（见 [[论文卡-2025-真实世界深伪检测评估]]）。→ **我的实验必须从干净样本出发施加后处理阶梯。**
- **误解 3**：把后处理鲁棒性与对抗鲁棒性混同。前者是**无意的**分布偏移，后者是**蓄意的**最坏情况扰动，威胁模型不同。

## 4. 例子

- FF++（c23）上 Xception AUC 95.7% → 经平台压缩后再测，性能显著下降。
- Deepfake-Eval-2024 的样本天然带后处理，导致开源模型 AUC 掉约 45–50%（见 [[证据卡-DFEval2024-01]]）。
