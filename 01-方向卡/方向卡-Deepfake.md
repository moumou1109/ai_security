# 方向卡 · Deepfake / AIGC 内容安全

## 1. 一句话方向

研究 AI 生成 / 篡改内容（尤其是人脸深伪）的**检测、溯源与鲁棒性**：不只问「平时准不准」，而要问「换一个生成器、加一层真实传播中的后处理之后，还准不准」。

## 2. 为什么选这个方向（课件 P33 的四要素）

| 要素      | 我的回答                                                 |
| ------- | ---------------------------------------------------- |
| 兴趣      | 对视觉内容真实性问题感兴趣：深伪直接冲击身份、证据和公众信任                       |
| 能力      | 有 CV / 深度学习基础，能读检测类论文、跑公开基线                          |
| 资源      | 课件 P32 指出该方向「论文、数据、Benchmark 丰富」，公开检测器与数据集相对好找       |
| 12 周可实施 | 先复现一个公开 baseline，再做跨生成器 / 后处理条件下的评测分析，规模可控，主要开销在单卡推理 |

## 3. 保护对象（被保护的到底是什么）

- 被伪造的个人：肖像、声音、名誉
- 看内容的人：对「视频/录音能不能信」的判断
- 依赖真实性判断的业务：内容平台审核、媒体核验、司法与金融取证（**待核实**：需要来源记录）
- 社会层面：公共信任与舆论环境（课件 P13 把 Deepfake 诈骗归到「社会/物理层」）

## 4. 系统视角下的攻击面（课件 P11 / P26：AI 安全是系统级问题）

| 环节 | 这个方向的典型风险 | 我关心的 |
| --- | --- | --- |
| 数据 | 训练数据被投毒，检测器学到「捷径特征」 | 待定 |
| 训练 | 检测器被植入后门 | 暂不涉及 |
| 模型 | 对抗样本让检测器误判；检测器自身被规避 | 候选子方向 2 |
| 输入 | 压缩、重编码、缩放、裁剪、超分、混剪等后处理导致漏检 | 候选子方向 3 |
| 内容 | 全新生成器 / 新伪造手法（unseen generator） | **候选子方向 1（当前主线）** |
| 现实后果 | 诈骗、伪证、舆论操纵、身份核验失效 | 选题动机 |

## 5. 候选子方向（下一步收缩用）

1. **跨生成器泛化**：换生成器后检测性能掉多少、为什么掉（当前主线）
2. 检测器的对抗鲁棒性：对检测器做攻击 / 规避
3. 后处理鲁棒性：模拟真实传播链（微信/短视频平台转码）后的检测性能
4. 伪造定位与可解释性：不只判真假，还指出伪造区域
5. 音频 / 多模态深伪检测
6. 水印与溯源、检测基准与威胁模型设计

> 每个子方向都要用课件 P36 的五问（保护什么 / 谁攻击 / 能做什么 / 怎么算成功 / 怎么实验）过一遍再决定。

## 6. 常见材料（**待核实**：用之前必须建来源记录或论文卡）

- 数据集候选：FaceForensics++、Celeb-DF、DFDC、DF40 等
- 检测基线候选：基于 Xception、EfficientNet、CLIP 等骨干的公开方法

> 本库规则：**没有来源的条目只能写成「候选/待核实」**，不能直接写进 RQ 和实验设计（课件 P9：证据必须可追溯）。

## 7. 已确定的收缩路径

```
Deepfake / AIGC 内容安全
      ↓ 选一个能被量化的失败模式
生成内容检测（真假判别）
      ↓ 限定黑盒攻击者 + 真实传播条件
跨生成器（unseen generator）+ 后处理 条件下的检测
      ↓ 变成可实验的问题
RQ-001（见关联 RQ 卡）
```

（收缩方法来自课件 P29 的示例。）
