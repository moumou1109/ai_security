# EXP-001 · 公开检测基线 in-domain 复现（Xception / CLIP-UFD）

## 1. 实验目的

验证 RQ-001 的哪一点：**建立性能上界参照 $\text{AUC}_{A0,B0}$**（in-domain clean），作为后续所有衰减指标（$\Delta_{gen}$、$\Delta_{post}$、$\Delta_{joint}$）的减数基准。

预期看到什么：在 FF++(c23) 上，Xception 与 CLIP-UFD 的 AUC 均应达到 0.95 以上（与 [[证据卡-DF40-01]]、[[证据卡-DeepfakeBench-01]] 报告的数量级一致）。若显著低于该水平，说明**预处理/环境有问题**，而不是方法有问题——这是复现的第一道 sanity check。

## 2. 环境与配置（规划）

| 项目 | 内容 |
| --- | --- |
| 机器 / GPU | 单卡（≥8GB 显存，推理为主） |
| 环境（Python / 框架） | Python 3.10 + PyTorch 2.x；优先用 DeepfakeBench 官方 install.sh 或 Docker |
| 代码仓库与 commit | https://github.com/SCLBD/DeepfakeBench（clone 后记录 commit hash） |
| 随机种子 | 固定 seed=42（推理阶段影响有限，仍记录） |

## 3. 数据与模型（规划）

- **数据集**：FaceForensics++（c23，轻度压缩，作为 in-domain 训练/测试集）；使用 DeepfakeBench 提供的统一预处理版本（DLIB 对齐 + 裁剪）。
- **划分方式**：沿用 DeepfakeBench 的标准化 JSON 切分，不自行重划（保证可比）。
- **模型 / 基线**：
  1. Xception（DeepfakeBench 提供预训练权重）
  2. EfficientNet-B4（对照）
  3. CLIP-UFD（CLIP:ViT-L/14 + 线性探针，[[论文卡-Ojha2023-CLIP通用伪造检测]] 官方权重）
- **对照**：频域 sanity baseline（DCT 统计量 + 逻辑回归）。
