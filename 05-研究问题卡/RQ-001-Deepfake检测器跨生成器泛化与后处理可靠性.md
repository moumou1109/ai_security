# RQ-001 · Deepfake 检测器在跨生成器与后处理条件下的可靠性

## 0. 一句话问题（V0.2）

**在一个受控的二维条件下——「生成器维度（训练时见过 / 未见）× 后处理维度（无 / 轻 / 中 / 传播链级）」——公开 Deepfake 检测器的判别性能如何衰减？哪个维度的影响更大，两者是否存在叠加（超线性）效应，以及哪一类检测器（空域 CNN / 频域 / 通用预训练特征）最先失效？**

> V0.1→V0.2 的收紧：把「可靠性会下降多少」这个模糊问题，改写为「在 2×4 网格上量化衰减曲面，并给维度效应排序」这一可实验的形式。

## 1. 动机与背景

- **动机**：
  1. 课件 P4 把 Deepfake 检测的红色风险标为「未知生成器」；
  2. 领域已有多份独立证据表明检测器在未见生成器上崩塌——AUC 从 0.94–0.99 跌到 **0.49–0.62**（[[证据卡-Croitoru2024-01]]）；
  3. 真实传播链（平台压缩/转码）是**第二个独立失效来源**——自开源模型在在野数据上 AUC 下降 **45–50%**（[[证据卡-DFEval2024-01]]），压缩+模糊可使平均准确率从 94.7% 降到 67.8%（[[证据卡-Robustness2026-01]]）；
  4. **但两个维度极少被联合、受控地研究**——现有工作要么只做跨生成器（DF40、BioDeepAV），要么只做退化（ProFake），没有人在同一个 2×4 网格上量化联合效应。
- **现有工作（A / B / C）及其不足**：

| 工作 | 做了什么 | 不足 |
| --- | --- | --- |
| A. [[论文卡-Yan2024-DF40下一代深伪检测基准]] | 40 种伪造技术、4 种评测协议、含 open-set | 对「传播链后处理」无系统覆盖 |
| B. [[论文卡-Croitoru2024-生成式AI时代深伪检测综述]] | 综述 + BioDeepAV OOD 基准 | 仅生成器维度，无受控后处理 |
| C. [[论文卡-Xu2024-ProFake质量退化鲁棒检测]] | 量化质量退化影响、提出鲁棒训练法 | 生成器维度固定；重训练而非评测 |
| D. [[论文卡-Chandra2025-DeepfakeEval2024真实场景基准]] | 真实在野数据评测 | 退化是「天然混在一起」的，不可分解 |

- **这些工作解决不了的障碍（barriers）**：跨生成器失效的机理是**捷径学习**——检测器学的是生成器指纹而非伪造本质（[[证据卡-Ojha2023-01]]，LDM 假图检测准确率仅 3.05%）。若真如此，则「破坏指纹」的后处理应与「替换生成器」产生**同向且可能叠加**的衰减。现有工作没有验证这一点。
- **为什么本方向有希望**：公开数据集（DF40、FF++、Celeb-DF）与开源检测器（DeepfakeBench 提供 36 个含权重的实现）齐备（课件 P32）；**评测不需要训练大模型**，单卡推理即可；后处理变换完全可控、可复现。

## 2. 威胁模型（课件 P28 六问）

| 问题 | V0.2 的回答 |
| --- | --- |
| 攻击谁（保护对象） | Deepfake 检测系统的输出（真假标签与置信度），进而影响内容审核 / 媒体核验 / 取证决策 |
| 攻击什么阶段 | **输入阶段**：只改「喂给检测器的内容」；不改检测器架构或参数、不做投毒、不碰训练流程 |
| 攻击者知道什么 | 主实验为**黑盒**（不知道检测器结构与参数、不能查询）；另设**灰盒**对照（假设攻击者知道检测器所用骨干家族，从而选择最不利的生成器/后处理组合） |
| 攻击者能改什么 | ① 换用训练时未见过的生成器 / 伪造手法（unseen generator）；② 对内容施加后处理：JPEG/H.264 压缩、缩放、高斯模糊、亮度对比度、旋转、超分、再压缩 |
| 预算 | 离线生成 + 变换无查询次数限制；算力预算限制在**单卡可复现**规模（推理为主，训练仅做小规模微调对照） |
| 成功标准 | 见下方 §3 的量化阈值（相对 in-domain clean 基线的绝对下降） |

## 3. 实验设计（V0.2：数字与阈值已填）

### 3.1 二维自变量网格

**维度 A：生成器（训练见过 / 未见）**

| 条件 | 定义 |
| --- | --- |
| A0 in-domain | 训练集内同族生成器 + 同分布测试 |
| A1 cross-domain | 换数据集但同伪造类型 |
| A2 cross-forgery | 同域内换伪造类型（换脸→表情重演等） |
| A3 **open-set（unseen generator）** | 训练时完全未见的生成器 / 伪造技术族 ← **核心** |

**维度 B：后处理强度（4 档，全部从干净样本出发）**

| 档位 | 变换组合 | 依据 |
| --- | --- | --- |
| B0 clean | 无 | 性能上界参照 |
| B1 轻度 | JPEG q=90 + 0.8–1.0× 缩放 | [[证据卡-Robustness2026-01]] 区间下沿 |
| B2 中度 | JPEG q=60 + 0.5× 缩放 + 轻度高斯模糊(σ=0.01) | 区间中段 |
| B3 **传播链级** | JPEG q=30 → 缩放 0.25× → H.264 转码(码率 ≤500kbps) → 再 JPEG q=40 | 多平台二次转码仿真；区间上沿 + [[证据卡-RealWorld2025-01]] 操作清单 |

> **方法学硬约束（来自 [[证据卡-RealWorld2025-01]]）**：必须从**干净原生深伪**出发施加 B1–B3，**绝不能用已退化的样本**（否则出现饱和效应，性能变化比被压平到 0.9–1.1，低估真实影响）。

### 3.2 数据集

| 用途 | 数据集 | 来源 |
| --- | --- | --- |
| 训练（in-domain） | FaceForensics++（c23） | 经典基准；DeepfakeBench 提供预处理版 |
| 跨数据集测试 | Celeb-DF v2、DFDC | 同上 |
| **open-set 未见生成器** | DF40（40 种技术，取子集：换脸 5 种 + 表情重演 5 种 + 整脸合成 5 种） | [[论文卡-Yan2024-DF40下一代深伪检测基准]] |
| 外部验证（真实传播） | Deepfake-Eval-2024（图像子集 1975 张起） | [[论文卡-Chandra2025-DeepfakeEval2024真实场景基准]] |

### 3.3 基线（按「线索类型」分组，检验交叉假设）

| 组别 | 检测器 | 选取理由 |
| --- | --- | --- |
| 空域 CNN | **Xception**、EfficientNet-B4 | 经典、DeepfakeBench 最优骨干之一 |
| 频域 | **SPSL**、FreqNet（选做） | 跨域最强（AUC 78.75%，[[证据卡-DeepfakeBench-01]]）；但**预期对压缩最脆弱** |
| 通用预训练特征 | **CLIP + 线性探针（UFD 式）** | DF40 上最强（0.898，[[证据卡-DF40-01]]）；**主 baseline** |
| 伪造增强类 | SBI（选做） | 代表 2022 后主流路线 |

### 3.4 指标（clean / attack 与跨域指标分开报告，呼应课件 P25）

- 主指标：**AUC**、**ACC**；辅：**FNR（漏检率）**、FPR、EER。
- 派生指标：
  - **绝对衰减** $\Delta_{gen} = \text{AUC}_{A0,B0} - \text{AUC}_{A3,B0}$（纯生成器效应）
  - **后处理衰减** $\Delta_{post} = \text{AUC}_{A0,B0} - \text{AUC}_{A0,B3}$（纯后处理效应）
  - **联合衰减** $\Delta_{joint} = \text{AUC}_{A0,B0} - \text{AUC}_{A3,B3}$
  - **交互项** $\text{Interaction} = \Delta_{joint} - (\Delta_{gen} + \Delta_{post})$：$>0$ 表示**超线性叠加**（两者相互放大），$\approx 0$ 表示独立叠加。

### 3.5 成功标准（量化阈值）

| 编号 | 判定 | 阈值 | 依据 |
| --- | --- | --- | --- |
| S1 | 跨生成器显著失效 | $\Delta_{gen}$（AUC 绝对下降）≥ **0.15** | 严格于 DeepfakeBench 跨域落差；参照 Croitoru 的 0.3–0.4 级崩塌 |
| S2 | 后处理显著失效 | $\Delta_{post}$（AUC 绝对下降）≥ **0.10** | 参照 Frontiers 的 −26.9% 平均准确率退化 |
| S3 | 叠加效应存在 | $\Delta_{joint} \geq 0.25$ 或 $\Delta_{joint} > \max(\Delta_{gen},\Delta_{post})$ 且交互项 $> 0.05$ | 本卡定义 |
| S4 | 检测器分组差异 | 至少一组基线的 $\Delta_{joint}$ 显著小于另一组（组间差 ≥ 0.10 AUC） | 检验「频域 vs 通用特征」的交叉假设 |
| S5 | 最脆弱组合可排序 | 输出 生成器×后处理 网格的衰减曲面，识别最脆弱格子 | RQ 的交付形式 |

### 3.6 对照

1. **in-domain clean（A0,B0）**：性能上界参照；
2. **sanity baseline**：频域特征（DCT 统计量）+ 线性分类器，验证「任务本身可学」；
3. **后处理但同生成器（A0,B3）** vs **换生成器但无后处理（A3,B0）**：用于拆解两个维度；
4. **随机猜测线（AUC=0.5）**：判定「是否已退化为无信息」。

### 3.7 预期结果（不预设幅度，预设方向）

- 方向 A：A3 条件下所有检测器 AUC 显著下降（S1 应成立）；
- 方向 B：B3 条件下显著下降（S2 应成立）；
- 方向 C（可证伪的核心假设）：**频域方法在 B3 下衰减最大**（高频被压缩截断），CLIP 类衰减相对最小 → 若成立则支持「线索类型决定脆弱度」；若不成立，需修正对频域鲁棒性的判断。
- 方向 D：联合衰减**大于**两单独衰减之和（存在交互放大）——即「真实攻击者同时换生成器 + 走平台传播」比任一单因素都更危险。

| --- | --- |
| 保护什么？ | 内容真实性判断（真假标签与置信度） |

## 7. 这张卡现在还不合格的地方（诚实记录）

1. **阈值 S1–S5 是我自己定义的**，尚缺「领域公认阈值」支撑 → 需在 EXP-001 拿到基线数字后，用实际分布校准（可能偏松或偏紧）。
2. 后处理 B3 的「传播链级」组合中，压缩参数的**顺序与步数**会显著影响结果 → 需要在 EXP-002 做参数敏感性分析，而非一次定死。
3. DF40 子集的选取（各 5 种）带主观性 → 需在实验卡中记录选取理由与随机种子。
4. 灰盒对照的具体形式（如何定义「知道骨干家族」）需在 EXP 中细化。
