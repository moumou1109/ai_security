# 论文卡 · Croitoru 2024（Generative AI Era 综述）

## 0. 一句话总结

这是一篇覆盖**图像/视频/音频/多模态**全媒体类型的深伪综述：构建了生成与检测方法的分类体系、整理了数据集与排行榜，并**新建了多模态 OOD 基准 BioDeepAV**，实证结论是——**当前最先进的检测器无法泛化到未见生成器产生的深伪**。

## 1. 元信息

- 论文链接：https://arxiv.org/abs/2411.19537
- 代码 / 数据（含新基准）：https://github.com/CroitoruAlin/biodeep
- 阅读程度：摘要 + 结论 + Table 5 关键结果

## 2. 研究问题

现有深伪检测的评测（包括排行榜）是否代表了对**新生成器**的检测能力？分布偏移（distribution gap）对检测器影响多大？

## 3. 方法

- 核心思路：综述 + 分类学（taxonomy）+ 新基准。
- 关键构成：
  1. 按「修改/生成流程」划分深伪种类，构建生成方法与检测方法的分类学；
  2. 汇总检测数据集，给出各主流数据集上最优检测器的最新排名；
  3. 新建 **BioDeepAV** 多模态基准，在**分布外（OOD）**内容上评测检测器。

## 4. 实验设置

| 项目 | 内容 |
| --- | --- |
| 数据集 | 汇总主流数据集 + 自建 BioDeepAV（OOD） |
| 基线 | StA、XceptionNet、F3Net、RECCE、TALL、UCF、MRDF 等 SOTA 检测器 |
| 指标 | AUC |
| 训练 / 推理条件 | 各检测器按其原始论文设置训练，在 BioDeepAV 上直接测试（OOD） |

## 5. 主要结果（Table 5：Original Test 集 vs BioDeepAV，AUC）

| 方法 | Original Test | BioDeepAV（未见生成器） |
| --- | --- | --- |
| StA | 0.9420 | 0.6195 |
| XceptionNet | 0.9637 | 0.5677 |
| F3Net | 0.9449 | 0.5010 |
| RECCE | 0.9422 | 0.5001 |
| TALL | 0.9987 | 0.4935 |
| UCF | 0.9527 | 0.4882 |
| MRDF | 0.9243 | 0.5852 |

> 关键读法：**同域 AUC 普遍 0.94–0.99，切换到未见生成器后集体跌到 0.49–0.62**，其中 TALL 甚至低于随机猜测线（0.5）。这是「训练集内准确率没有安全意义」最有力的证据。

## 6. 局限与作者自己承认的问题

- 综述性质，方法细节不如单篇方法论文深入。
- BioDeepAV 会随生成技术进步而过时（作者亦呼吁持续更新跨域/开集基准）。
- 作者展望中指出：无监督/单类学习方法目前仍落后于有监督方法；可解释检测研究不足。
