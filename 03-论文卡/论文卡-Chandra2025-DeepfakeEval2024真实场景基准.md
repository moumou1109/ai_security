# 论文卡 · Deepfake-Eval-2024（Chandra 2025）

## 0. 一句话总结

学术数据集上的高准确率**不能代表真实世界**：作者构建了 2024 年从社交媒体与检测平台用户处收集的**真实在野（in-the-wild）深伪**基准 Deepfake-Eval-2024（45 小时视频 / 56.5 小时音频 / 1975 张图像，覆盖 88 个网站、52 种语言），发现开源 SOTA 检测器的 **AUC 相对以往基准下降约 50%（视频）/ 48%（音频）/ 45%（图像）**。

## 1. 元信息

- 论文链接：https://arxiv.org/abs/2503.02857
- 代码 / 数据：https://github.com/nuriachandra/Deepfake-Eval-2024
- 阅读程度：摘要 + 4.1/4.2 结果章节

## 2. 研究问题

在「实验室数据集」上的检测性能，能否迁移到**真实传播环境**（已经过平台压缩、转码、混剪）中的深伪？学术基准是否已经过时？

## 3. 方法

- 核心思路：把评测搬进「野外」。
- 关键构成：
  - 数据来自**社交媒体 + 检测平台用户**，代表真实传播形态（含平台后处理）；
  - 覆盖最新操纵技术与多语言、多来源内容；
  - 同时评测开源模型、商业模型、以及在基准上微调的模型。

## 4. 实验设置

| 项目 | 内容 |
| --- | --- |
| 数据集 | Deepfake-Eval-2024（45h 视频 / 56.5h 音频 / 1975 图，88 网站 / 52 语言） |
| 基线 | 开源 SOTA：GenConViT、FTCN、Styleflow（视频）；AASIST、RawNet2、P3（音频）；UFD、DistilDIRE、NPR（图像）；另含商业检测工具 |
| 指标 | AUC、Accuracy、Precision、Recall、F1 |
| 训练 / 推理条件 | 先做 off-the-shelf 评测；再在基准子集上微调对照 |

## 5. 主要结果

- **AUC 相对以往学术基准下降：视频 50%、音频 48%、图像 45%**。
- **开源模型最高 AUC 仅 0.58**，许多模型 AUC 接近 0.5（等同随机猜测）→ 说明它们学的是学术训练集里的相关性，而非真实伪造线索。
- **微调后改善**：AUC 平均提升 57.6%（视频）/ 80.6%（音频）/ 4.5%（图像）；但峰值准确率仍只有 视频 0.75 / 音频 0.86 / 图像 0.63，**低于人类深伪分析师约 90% 的下界估计**。
- 简单模型（如 UFD 单层）微调后学成「全判为假」，说明部分架构不适合迁移到真实分布。

## 6. 局限与作者自己承认的问题

- 在野数据的采集与人工标注**成本高、易出错**，不适合大规模训练。
- 基准会因生成技术快速演进**迅速过时**。
- 图像部分的微调数据量偏小，导致图像模型提升有限。

## 7. 与我的方向 / RQ 的关系

- **支持（最强）**：这是「**后处理/真实传播链会让检测性能崩塌**」的直接证据——因为 in-the-wild 数据天然带平台压缩与转码。为 RQ-001 的「后处理条件下可靠性」这一半提供了关键背书。
- **可直接借用**：Deepfake-Eval-2024 作为「真实传播条件」的外部验证集（或作为我构造后处理的仿真目标）。
