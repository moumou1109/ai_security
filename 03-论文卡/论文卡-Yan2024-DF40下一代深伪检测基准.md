# 论文卡 · DF40（Yan 2024）

## 0. 一句话总结

作者认为现有深伪检测的评测协议（在 FF++ 训练、在别的数据集测试）本身有缺陷，于是构建了含 **40 种伪造技术**的大规模数据集 DF40，用 4 种评测协议、8 个代表性检测器做了 2000+ 次评测，结论是：**同域内的高性能会显著高估泛化能力，跨域/开集（unseen generator）条件下检测器普遍大幅下降**。

## 2. 研究问题

现有「在某个数据集上刷到 SOTA」的排行榜，能否代表检测器在真实、多样的深伪面前的能力？如果不能，差距的根源在哪？

作者定位到三个「数据集层面的元凶」：

1. **伪造多样性不足**：多数数据集只覆盖部分伪造类型（FF++ 只有 2 种换脸 + 2 种表情重演）。
2. **伪造真实性过时**：主流训练集 FF++ 用的是四年前的伪造技术，在这些旧技术上「练出来的本领」无法保证检测今天的 SOTA 深伪。
3. **评测协议单一**：多数工作只在单一伪造类型内评测，阻碍了通用检测器的发展。

## 3. 方法

- 核心思路：不是提出新的检测器架构，而是**构建基准 + 重新设计评测协议**，把领域注意力从「刷榜」拉向「多样性、真实性、开集鲁棒性」。
- 关键构成：DF40 数据集包含 **40 种深伪技术**，分四类：10 种换脸（Face-swapping）、13 种表情重演（Face-reenactment）、12 种整脸合成（Entire Face Synthesis）、5 种人脸编辑（Face-editing）；含 0.1M+ 视频片段与 1M+ 图像，覆盖 PixArt-α、DeepFaceLab、HeyGen 等近期系统。

## 4. 实验设置

| 项目 | 内容 |
| --- | --- |
| 数据集 | DF40（自建，40 种伪造技术），并含 GenImage（非人脸 AIGC）做迁移测试 |
| 基线 | 8 个代表性检测器，其中最常被引用为强基线的是 **CLIP（CLIP-base / CLIP-large）与 Xception** |
| 指标 | AUC / 平均分（含 cross-forgery、cross-domain、open-set、pretraining-transfer 四个协议） |
| 评测协议 | ① 域内跨伪造类型；② 跨域；③ **在未知生成器与未知域上的开集评测**；④ 预训练与迁移评测 |
| 训练 / 推理条件 | 单卡级别可复现（检测器规模远小于 LLM） |

## 5. 主要结果

（以下数字来自论文摘要 / 结果表，逐条已抽成证据卡）

- 在 DF40 相关测试上，**CLIP-large 平均分 0.898，CLIP-base 0.814，Xception 仅 0.644**；迁移到 GenImage 时分别是 0.746 / 0.639 / 0.535。
- **域内性能会显著高估泛化**；跨域与开集性能明显更难。
- 检测器效果在**不同伪造家族与不同生成器之间差异巨大**。
- **更广的训练数据能改善迁移**；在人脸深伪上训练的检测器对非人脸 AIGC 图像有一定迁移潜力。
- 超分辨率（super-resolution）会显著改变可检测性。

## 6. 局限与作者自己承认的问题

- 这是一份基准研究，本身不给出新的检测方法；它揭示问题但未解决问题。
- 数据集会随时间过时（作者也承认伪造技术演进很快）。
- 论文与作者的另一工作 [arXiv:2108.05080] 存在文本重叠（arXiv 管理员注记已标出）。

## 10. 我的判断（可以是错的，但要写下来）

DF40 证明了「排行榜失真」这件事，但它的协议仍以人脸伪造为主、且对传播链后处理覆盖不足。一个 12 周可做的差异化切入点：**在 DF40/DeepfakeBench 的协议上，系统叠加「社交媒体式后处理」这一变量，量化 unseen generator × 后处理 的联合衰减**。这比单纯再刷一个 SOTA 更可复现、更有部署意义。
